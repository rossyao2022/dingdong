# M5 题库运营与家长端验收（2026-09-12）

本轮沿用 Django/DRF、PostgreSQL、Redis/Celery 与原生前端。参考仓库 `d754a5bf9ea8e71ca64a850d2e26aa321fe8ab38` 未改动；复用了其四个探索情境和兴趣岛视觉。范围清单见 `M5_GAPS.md`。

## 已完成

- 后台题库不再要求编辑 JSON：可逐题维护题干、单选/多选、选项、必填、最大选择数、增删与上下排序；支持空草稿、家长视角预览、保存、发布和复制为新版本。发布前有未保存编辑会提示先保存。已发布页面以可读预览呈现。
- 题库版本保存用途、名称、说明；已发布/停用内容不可原地修改，旧会话固定引用创建时版本。发布新版本只停用同 code 的旧版本。复制具有独立 UUID、版本号、题目副本，并执行工作人员权限与 CSRF 校验。
- 探索体验允许 1–10 题；正式测评流程测试暂用 20–30 题。这个范围是当前本地产品约束，不是已确认的专业量表规范；正式量表和题量待甲方确认。没有把所有问卷固定为 22 题。
- `seed_mock` 迁入原参考四题及 22 道可读日常情境题，涵盖探索、表达、观察、合作。八个活动也有具体材料与三步说明。已知占位种子停用并创建 `readable-v2`，不会覆盖旧答卷、历史报告或运营发布内容。
- 家长端按用途显示入口；后台额外发布题库也有入口，独立继续各题库答卷。答案服务器保存，按首个未完成必填题恢复；返回上一题先保存当前选择，可返回修改，支持可选题和多选校验。并发冲突提供读取最新记录入口。
- 探索完成只保存和展示逐题选择，不创建画像、能力分数或专业报告；重复完成幂等。测评流程仍使用有界的五张确定性测试图片，拒绝真实指纹。
- 新初始报告列出来源题库名称/版本和实际答卷选择；专业结果明确为“尚未接入 / 暂无数据”。不再注入 65 分一类的合成能力指标。历史报告保持不可变，不追溯改写。
- 检查活动、档案、授权、关联、报告、支持与回执页面；移动账户页补齐“伙伴引导 / 家长支持”入口。关联失败有提示，帮助事项和删除事项有真实回执。

真实 Chrome（Playwright `channel: chrome`）操作登录、建档和页面，直接连接 Django 与 PostgreSQL，无 API 拦截或假响应。报告由真实 Celery Worker 生成；外部输入由 `inject_fixture` 注入，不直接制造业务成功结果。

浏览器覆盖：

1. 活动开始、步骤、完成、刷新恢复和退出清理。
2. 日常问卷完整作答 → 五张合成样例 → 实际报告队列 → 可读报告。
3. 数据库测试凭据关联 → CA 主动同步 → 阶段报告 → 撤回授权。
4. 手机尺寸布局、儿童切换、跨标签退出。
5. 家长申请删除 → 工作人员实际处理 → 无儿童时仍能读去标识回执。
6. 小岛出发与各主页面入口。
7. 原四题体验、恢复、返回修改、完成及选择结果。
8. 后台可视化新建、预览、发布、复制再发布；家长读新题干，旧答卷仍用旧题干并可完成。
9. 移动各页面、编辑档案、无效关联提示、帮助回执和新增快捷入口。

## 初始化与运行

```sh
cd backend
uv run python manage.py migrate
uv run python manage.py seed_base
uv run python manage.py seed_mock --dataset phase1-v1 --mode cold
uv run python manage.py collectstatic --noinput
uv run python manage.py runserver 127.0.0.1:8017
# 另开终端按 README 启动 Worker、Beat、frontend。
```

`warm` 现在仅为输入初始化的兼容别名，不再创建完成/跳过记录。没有通用 reset 命令。旧开发数据保留；纯冷启动用隔离数据库。浏览器测试留下自己的家庭/答卷/业务记录；其临时内容人员停用，测试发布题库完成验收后停用，旧会话仍可读取。没有默认工作人员密码。

前端 `http://127.0.0.1:4173/`；后台 `http://127.0.0.1:8017/admin/core/questionnaireversion/`。预览后端及 Worker 已重启到新代码，Django 使用自动重载。本任务已向 Codex 请求打开最新报告入口；应用返回 queued（任务显示时打开）。CUA 当前两次超时，因此不声称已经观察到用户原标签页刷新完成。
