## 关键行为

| 场景 | 行为 |
|---|---|
| 同 request_id 创建/提交 | 相同输入标识返回已有记录，冲突返回 409 |
| 答案 revision 过期、未知题码/选项 | 409 / 422；已发布题库内容禁止原地修改 |
| 缺槽、重复槽、非指定合成图、超过上限 | 422 / 413；不创建算法尝试 |
| 算法明确失败 | needs_recapture；注入恢复输入后可用新请求重新采集 |
| 算法超时或进程中断 | result_unknown；相同键查询结果，拒绝新提交，可取消 |
| 处理期间撤回授权 | 不写入画像；待处理报告也重新检查授权 |
| 报告重复投递 | 唯一结果约束、状态锁和执行令牌避免重复结果 |
| 报告失败 | 数据库保存失败尝试并延后重试，最多 5 次 |
| 缺报告模板 | waiting；发布模板后扫描恢复 |
| Worker 租约过期 | 旧尝试 abandoned，补投恢复；提交需令牌匹配 |
| 跨家庭读取、撤回 | 404 |

图片只在请求内存处理；验证后、调用数据库适配器前关闭缓冲区。画像仅保存白名单非生物指标；队列只传任务 ID。测试将 Django 默认内存阈值降到 1 字节，确认仍不写临时目录，并检查业务行和捕获日志不包含输入文件名。没有任何真实指纹参与测试。此结论限定当前 Django/WSGI 路径，生产代理、ASGI、进程崩溃转储等尚未验收；production 仍拒绝启动。
