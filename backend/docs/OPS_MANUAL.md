# 叮咚运营后台使用手册

面向日常运营人员。本手册只讲"在哪个页面做什么事"，不要求理解数据库表、UUID、JSON 或命令行。

- 后台入口：`/ops/`（本地 `http://127.0.0.1:8017/ops/`，公网 `http://110.42.225.196/ops/`）
- 登录方式：后台账号（用户名 + 密码）。家长手机号不能登录后台，后台账号也不能登录家长端。
- 首次登录后请先改密码：右上角账号 → 修改密码。

---

## 0. 三个基本概念

| 概念 | 含义 | 运营需要注意什么 |
| --- | --- | --- |
| 家庭 / 儿童 | 家长账号是"家庭"，儿童是家庭下的档案，没有独立儿童登录 | 搜索家庭用家长手机号或家长称呼；搜索儿童用儿童称呼 |
| 版本（题库 / 活动） | 题库和活动都是"多版本"的：草稿 → 已发布 → 已停用 | 已发布版本不能原地改；要改就"复制为新版本" |
| 答卷 / 报告 | 家长做完题生成答卷，答卷再生成报告 | 答卷固定它作答时的题库版本；改题库不会改历史答卷 |

状态词都做了中文业务化，例如任务状态显示"排队中 / 处理中 / 等待依赖 / 已完成 / 失败"，不会出现英文枚举或系统代码。失败原因下方会用小字附上系统代码（如 `RENDER_FAILED`），那是给技术同事对日志用的，运营可以忽略。

## 1. 工作首页（`/ops/`）

每天上班先看这一页。

**统计数字的口径**（鼠标停在数字上或看卡片下方说明即可看到）：

| 指标 | 口径 |
| --- | --- |
| 家庭总数 | 状态为"正常"的家庭记录数（含历史测试家庭） |
| 在册儿童 | 状态为"正常"的儿童档案数，不含已归档 |
| 近 7 天新增儿童 | 创建时间在过去 7 天内的儿童档案数 |
| 近 7 天新增答卷 | 创建时间在过去 7 天内的答卷数，含未提交草稿 |
| 近 7 天生成报告 | 生成时间在过去 7 天内的报告份数 |
| 近 7 天活动记录 | 创建时间在过去 7 天内的活动记录数，含进行中与已完成 |

所有数字都是当前数据库的实时统计，没有预置或写死的值。数据库里有多少测试数据就显示多少，这是正常的。

**待办清单**只显示当前角色能处理的项：

- 待处理服务事项（"待处理"或"处理中"）→ 点"处理"进入事项详情
- 报告生成异常（状态为"失败"的任务）→ 需要技术运维角色，点进去重试
- 等待依赖的任务（缺少已发布模板或规则而暂停）→ 发布对应内容后会自动继续，**不需要手工重试**
- 未发布的题库草稿 → 提醒内容运营去发布

**快捷入口**按角色显示，点不到的功能说明当前账号没有该权限，不是页面坏了。

## 2. 家庭与儿童（`/ops/families/`）

### 查询家庭

在搜索框输入**家长手机号**或**家长称呼**，回车。结果分页显示，页码在列表下方。

### 家庭详情（`/ops/families/<家庭>/`）

一页看全这个家庭：家庭成员、儿童档案列表、家庭信息。

**可以做**：

- 冻结家庭 / 恢复家庭 —— 冻结后家长端不能再新增儿童、发起新答卷；历史数据保留。这是一个有影响的操作，页面会先弹出影响说明再让你确认。
- 点儿童名字进入儿童详情。

### 儿童详情（`/ops/children/<儿童>/`）

聚合了运营真正需要看的全部内容：

| 区块 | 内容 |
| --- | --- |
| 基本信息 | 称呼、性别、生日、状态 |
| 更正儿童档案 | 改称呼 / 性别 / 生日，保存后立即生效并留审计 |
| 答卷 | 该儿童的全部答卷，含题库版本与提交时间 |
| 报告与画像 | 已生成的报告版本；点进去看正文 |
| 活动记录 | 参与过的活动与完成情况 |
| 伙伴关联与同步 | 外部关联状态；可暂停 / 恢复同步（需要技术运维角色） |
| 授权记录 | 家长同意 / 撤回同意的记录 |
| 服务记录 | 这个儿童提过的所有服务事项 |
| 该档案的操作记录 | 谁在什么时候改了什么 |

页面底部有"返回家庭"链接，不会让你迷失在层层详情里。

**常见任务**：

- 家长打电话说孩子称呼写错了 → 搜索家庭 → 进儿童详情 → 更正儿童档案 → 保存
- 家长说报告没出来 → 进儿童详情看"报告与画像"和"答卷"，如果答卷存在但报告缺失，多半是生成任务失败，去报告管理或生成任务页处理

## 3. 题库管理（`/ops/questionnaires/`）

> 需要"内容运营"或"管理员"角色。

### 版本生命周期

```
新建题库草稿 → 编辑题目 → 预览 → 发布 → （要改就）复制为新版本 → 旧版本停用
```

- **草稿**：可以随时保存，未完成的题目不影响家长端。
- **已发布**：家长端可见。**不能原地修改**——这是硬规则，因为家长可能正在作答。
- **已停用**：家长端不再展示，但引用过它的历史答卷不受影响。

### 新建题库

1. 点"新建题库草稿"
2. 填写基本信息：标题、说明、用途
   - **探索体验**：1–10 题
   - **测评流程（测试）**：20–30 题
   - 题量在**发布时**校验，编辑过程中随便保存
3. 进入编辑页，逐题填写题干、选项、顺序、必填规则
4. "保存并预览"看家长端的样子，或"保存草稿"先存着
5. 满意后点"发布"

### 编辑题目

编辑页是可视化操作，**不需要写 JSON**：

- 题干、选项都是普通输入框
- 拖动或用按钮调整题目顺序
- 勾选"必填"、设置多选的最大可选数
- 增加 / 删除题目与选项

题目数量、选项完整性会在发布时统一校验，不通过会明确告诉你是第几题的问题。

### 修改已发布的题库

已发布版本页面上不会有"保存"按钮，只有"复制为新版本"。

1. 在已发布版本页点"复制为新版本"
2. 系统生成一份新草稿，内容与旧版本一致
3. 在草稿上修改、发布
4. 发布后**同一题库的旧版本自动停用**，家长端立即切到新版本
5. 历史答卷仍然指向它们作答时的旧版本，不会被改写

### 停用

在版本页点"停用"。停用后家长端不再展示该版本。已产生的答卷与报告不受影响。

## 4. 活动管理（`/ops/activities/`）

> 需要"内容运营"或"管理员"角色。逻辑与题库管理一致（草稿 / 已发布 / 已停用，已发布不可原地改，要改就复制）。

### 新建活动

1. 点"新建活动草稿"，填写标题与说明
2. 进入编辑页维护：
   - **活动信息**：标题、说明
   - **风格标签**：家长端按这些标签匹配活动，**至少选一种才能发布**
   - **活动步骤**：每一步的指导语与提示文字，可增删、可排序
   - **材料**：活动需要的材料清单
3. "保存并预览"确认家长端呈现，然后"发布"

### 改已发布的活动

同题库：复制为新版本 → 修改 → 发布 → 旧版本自动停用。

**已开始或已完成的活动记录不会被内容修改打断**：活动记录固定它开始时引用的版本，改内容只影响之后新开始的活动。

## 5. 报告管理（`/ops/reports/`）

> 查看需要"运营 / 技术运维 / 管理员"角色；重试需要"技术运维 / 管理员"角色。

### 查报告

- 按儿童称呼搜索
- 按数据来源筛选

点"查看内容"进入报告详情，可以看到报告正文、生成状态、以及产出它的生成任务。

### 报告没出来怎么办

报告不是即时生成的，它由后台任务产出。如果家长反馈报告没出现：

1. 先到儿童详情确认答卷是否已提交
2. 答卷已提交但没有报告 → 到"生成任务"页（`/ops/jobs/`）看有没有失败任务
3. 失败任务页面会给出：
   - **业务语言的失败原因**（如"报告内容生成失败"）
   - **处理建议**（如"该原因通常是临时问题"）
   - 是否**允许重试**

### 重试失败的生成任务

> 只有"技术运维"或"管理员"角色能重试。

1. 打开失败任务详情
2. 点"重试该任务"，先读弹出的影响说明：
   - 重复点击不会产生重复任务
   - 每次重试都会记录操作人
   - 如果依赖仍然缺失，任务会再次失败
3. 确认后任务重新排队

**幂等保护**：重复点击或两人同时点击，只会重排一次，第二次会提示"任务已经在处理中"。

**状态为"等待依赖"的任务不要手工重试**：那是缺少已发布的模板或规则，把对应内容发布出去，系统会自动继续。

## 6. 服务事项（`/ops/services/`）

> 查看需要"运营 / 技术运维 / 管理员"角色；处理需要"运营 / 技术运维 / 管理员"角色；删除需要"技术运维 / 管理员"角色。

服务事项是家长在家长端提交的求助、删除或更正申请。这是运营最日常的闭环工作。

### 处理流程

1. 在工作首页"待处理服务事项"点"处理"，或到 `/ops/services/` 按状态 / 类型 / 儿童或手机号筛选
2. 事项详情页会显示：
   - 事项类型、提交家长（含手机号）、提交时间
   - **处理指引**——按类型给出具体该做什么
   - 该儿童的其他事项，便于看上下文
3. 按指引线下处理（例如先电话联系家长确认）
4. 回到页面：选择"处理结果"，填写"处理说明"
   - 处理说明建议至少写一句，方便后续接手的人了解上下文
   - 说明会记录在事项历史与操作审计里
5. 点"确认已处理"

**幂等保护**：事项已处理后再点，会提示已处理过，不会产生重复记录。

**常见事项类型**：

| 类型 | 建议做法 |
| --- | --- |
| 求助 | 联系家长确认问题，能解决就解决，解决不了转到技术同事 |
| 更正 | 到儿童详情页点"更正儿童档案"改好，再回来确认已处理 |
| 删除 | 需要技术运维执行，运营可以查看进度 |

处理历史在页面下方，能看到谁在什么时候做了什么，不会丢失。

## 7. 账号与权限（`/ops/accounts/`、`/ops/audit/`）

> 账号管理需要"管理员"角色；操作审计对多数角色开放。

### 新建后台账号

1. 账号管理 → "新建账号"
2. 填写用户名、姓名、初始密码
3. 选择角色（页面直接给出常用组合，不用记权限点）
4. 保存后把用户名和初始密码交给本人，提醒首次登录改密码

### 常用角色组合

| 组合 | 适合谁 |
| --- | --- |
| 运营专员 | 只做家庭查询、服务事项、报告查看 |
| 运营专员（含题库活动） | 运营 + 内容维护 |
| 内容运营 | 只维护题库与活动 |
| 技术运维 | 处理生成异常、同步问题、数据删除 |
| 管理员 | 全部权限，含账号管理 |

### 改角色 / 停用账号

账号详情页可以：

- 保存角色变更（立即生效，下次请求按新角色判断）
- 停用 / 启用账号——**停用后该账号无法登录，已登录的会话会在下次请求时失效**
- 重置密码——给一个初始密码，让对方登录后自己改

### 修改自己的密码

右上角账号菜单 → 修改密码。改完当前会话保持登录，不会把你踢出去。

### 操作审计（`/ops/audit/`）

记录关键写操作：谁、什么时候、对什么对象、做了什么。

- **操作**列是中文，例如"家长开始答题""发布内容版本"
- **对象**列显示业务名称；没有名称的记录显示"类型 + 8 位编号"（如"后台任务 / 编号 1219a377"），报障时把这个编号给技术同事即可
- **说明**列是"中文键：中文值"，例如"题目数量：1""复制来源：v1（已发布）"
- 可按操作人和操作类型筛选，时间按北京时间显示

这份记录是只读的，任何人（包括管理员）都不能在页面上删改。

---

## 8. 权限不足 / 记录不存在

- 打开没有权限的页面 → 显示"这个页面当前账号打不开"，并说明需要什么权限，附"返回工作首页"按钮
- 打开已被删除或编号不对的记录 → 显示"没有找到这条记录"，附返回列表的入口

这两类页面都不会白屏，也不会把系统错误暴露给你。

---

## 9. 已知边界（请如实告知家长）

以下是**演示环境**的既有边界，运营在对外沟通时不要把它们说成正式能力：

- 短信验证码固定为 `00000`，不发送真实短信
- 外部伙伴数据来自数据库 fixture，不是真实供应商联调
- 不采集、不留存真实指纹
- 探索体验只记录本次选择，**不产出天赋、能力分数或专业结论**
- 专业量表题量、评分解释仍待甲方确认

遇到家长问到这些，按"当前是测试版本"如实说明即可。
