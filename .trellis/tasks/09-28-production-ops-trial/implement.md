# 执行清单

1. 核实 IP HTTPS 证书有效、旧业务路由和资源余量；核对 v0.3.10 发布包与镜像。
2. 在生产机安装 Docker 和 Compose，确认旧服务/端口未变。
3. 上传发布包与镜像；生成仅主机保存的独立 `.env` 和访问控制配置；启动 `dingdong-prod-trial`。
4. 检查 API、前端、迁移、数据库和容器健康；创建独立运营测试账号。
5. 新增 IP HTTPS 下叮咚路由并执行 `nginx -t`；检查公网未授权/已授权入口。
6. 用真实浏览器走登录、页面、退出；核对其他生产域名可达。
7. 写运营手册及部署/回滚记录，更新项目记忆，运行文档审核并提交本地改动。

失败时仅回滚本任务的 nginx 路由与 Compose 项目；保留数据库卷和部署材料供分析。
