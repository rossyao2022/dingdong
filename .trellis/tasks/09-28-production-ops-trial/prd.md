# 生产机运营试用部署与手册

## Goal

在晴幂生产机隔离部署 v0.3.10 运营试用实例，验证公网入口并交付运营操作手册和回滚记录。

## Requirements

- 在已确认的晴幂生产机 `1.15.23.152` 上运行与现有业务隔离的叮咚 v0.3.10 运营试用实例。
- 沿用已经在 tigery 测试通过的发布内容，独立数据库、密钥、容器和回滚点，不改动其他业务的运行状态。
- 用现有可信 IP HTTPS 证书提供家长端与运营后台入口，并阻止未获授权的人访问固定验证码演示系统。
- 清楚标明这是供运营测试的演示模式，不把合成数据、固定验证码或未完成的供应商对接写成真实生产能力。
- 交付运营可直接照做的操作手册、问题反馈方式，以及技术侧部署和回滚记录。

## Acceptance Criteria

- [x] 生产机独立服务启动，数据库与密钥不复用 tigery 测试环境；原有服务状态保持正常。
- [x] `https://1.15.23.152/dingdong/` 与 `/ops/` 通过浏览器访问，版本显示 `0.3.10`，登录、退出和主要页面实测成功。
- [x] 公网入口受访问控制；固定验证码、演示素材、真实供应商尚未闭环等限制在手册中明示。
- [x] 完成数据库备份/回滚办法和服务健康检查记录。
- [x] 运营手册不用技术术语指导日常操作，可单独转发。

## Notes

- 用户已确认生产机并要求可以跑起来；目前代码的真实生产模式被显式禁用，本任务上线范围仅是生产机上的运营试用实例。
- 不复用或改变 Seewow 生产 R2/CDN 设置；本任务与它无关。
