# 会展演示稳定性修复与指南更新

## Goal

落实参展审核中的我方修复，保证工作人员固定号演示可恢复、状态如实、手机步骤准确。

## Requirements

- demo 固定号禁止家长停用和换机，普通账户生命周期继续按现有规则执行。
- 绑定失败提供再次连接操作；未接通不展示聚合数值。重试复用同一账号，不长期保存 NFC 明文。
- 登录前刷新后给再次碰标签提示，URL 和浏览器 storage 不保存 NFC 明文。
- 发码按服务端冷却禁用并倒计时，刷新或退出登录不绕过冷却。
- 提供仅针对固定号原儿童的报告测试输入准备命令，通过真实 API 和 Worker 验证报告生成。
- 更正家长端手机入口和两份指南，补会展主链路操作截图及人工选方向、人设的说明。
- 本地提交修复、测试证据、发布包；远端发布遵守单独放行门禁。

## Acceptance Criteria

- [x] 后端保护与绑定状态回归测试先红后绿；普通账户回归通过。
- [x] 移动浏览器覆盖失败恢复、NFC 刷新提示、冷却、实际绑定与授权。
- [x] 演示报告输入限定固定号，准备后经真实提交和 Worker 得到报告。
- [x] 两份新版 PDF 含正确手机步骤、页面截图和已授权运营凭据，逐页检查通过。
- [x] 全量后端、前端单测、适当浏览器回归、契约和文档检查通过；本地提交并完成发布准备。
