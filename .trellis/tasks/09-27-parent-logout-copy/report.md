# 家长端退出入口与文案清理：本地验收

日期：2026-09-27。分支：`codex/release-v0.3.10`。本轮只改家长端展示与测试断言，未改后端接口或数据处理逻辑；测试环境仍为 v0.3.9，未部署此轮改动。

## 产品处理

- 页头增加常驻“退出登录”，未登录时隐藏。全新家长停在建档页、已有儿童档案和 390px 手机宽度均可退出。
- 直接删除后台发布、数据来源对照、同步时间戳、报告模板版本、内部账号说明等不影响家长行动的内容；设备编号只在主动展开“查看设备信息”后出现。
- 将机器人记录状态、删除申请进度改为家长能按此行动的提示。保留测评性质、授权范围、换机影响等必要说明。
- 测评提交阶段明确说明使用系统演示图片，按钮写“生成演示报告”，避免家长误以为系统采集了孩子的照片；相关完整流程 2 项重新跑通。

## 验证

- `npm run check`：通过；`npm run test:unit`：67 passed。
- 真实 Chrome：新增退出和文案用例 2 passed；受改动影响的旧流程 23 项中初跑 19 passed，4 项因旧文字/定位断言或报告就绪后轮询结束而失败，修正测试后定向 4 passed；成长周期桌面与 390px 浏览器 1 passed；演示报告提交相关流程 2 passed。另有账户与机器人标签专项 9 passed（本轮前段复测）。
- 部署配置测试 `uv run --no-sync --directory backend pytest ../deploy/tests -q`：9 passed；`uv lock --check` 与 `git diff --check`：通过。
- 测试写回的历史截图及 T-020 合成响应文件已恢复，未覆盖原有验收证据。

## 边界

本轮 UI 验证不等于 DingDong 正式接口联调完成。测试环境的数据源仍是合成 fixture，正式 NFC 规则、四子接口与真实推送仍待对方确认。
