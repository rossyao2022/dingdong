# 实施与验证

1. 基线：隔离本地服务、真实 Chrome 手机视口逐页截图与几何检查；写会失败的布局断言，定位具体挤压处。
2. 抽出可复用 HTML 构件，建立 Storybook HTML/Vite 配置和主要故事；确保故事与生产使用同一模块与三层 CSS。
3. 在 `client.css` 和最少量 `app.js` 模板中统一报告页节奏、手机表单、按钮与导航布局；保持参考 CSS 与业务逻辑不变。
4. 跑移动端布局 E2E、受影响业务 E2E、前端单测/语法、Storybook 构建；审查 320/390/430 与桌面截图。
5. 如需发布生产机试用实例，先备份/校验发布包，切换 Web 与必要服务，公网移动浏览器抽验；写报告、更新记忆、提交、归档。
