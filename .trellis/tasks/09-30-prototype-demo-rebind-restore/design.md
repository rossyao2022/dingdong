# 操作设计

固定 `ca_dingdong` 是对方 Prototype 唯一识别的演示号。当前同号记录已归档，正式账户规则禁止跨儿童复用。此次经用户单独放行，仅对原手机号、原儿童、原标签做一次演示环境恢复；不转移所有权，不删除历史数据。写入前在数据库事务内锁定记录并断言归属、标签摘要和活跃号约束。将 `status` 改为 `active`、`bind_state` 改为 `unbound`、`unbound_at` 清空并记录审计。这样现场碰标签时现有 API 会复用同一号、向 DingDong 再发 bind；不预先标记为已接通。既有 `dingdong_sync` 授权保持原状态，现场须按页面重新同意。
