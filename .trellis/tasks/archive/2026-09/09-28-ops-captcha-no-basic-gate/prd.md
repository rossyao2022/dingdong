# 运营登录图形验证码替代浏览器门禁

## Goal

在运营后台登录页加入服务端图形验证码与失败限流，移除生产机浏览器访问门禁，验证并部署更新。

## Requirements

- 移除生产机叮咚页面的浏览器 HTTP Basic 弹窗，让运营与家长直接到应用页面。
- 运营后台账号密码登录前必须通过页面内验证码；验证码由服务端生成和验证，短时有效、一次性使用。
- 多次错误密码尝试应受跨进程限流；验证码与限流不能暴露答案或账号存在性。
- 现有后台角色、审计、CSRF、家长端业务流程和其他生产站点保持正常。
- 更新可转发运营手册、部署记录与回滚办法，不再给运营分发外层门禁账号。

## Acceptance Criteria

- [x] 公网访问 `/ops/login/` 与 `/dingdong/` 不出现浏览器访问门禁。
- [x] 后台登录缺失、错误、过期、重放验证码均不能进入；正确验证码+正确账号密码可进入，退出可用。
- [x] 错误账号密码限流在两个应用进程间共享，并保留后台审计与角色行为。
- [x] 家长端固定码试用流程经真实浏览器复核；其他生产站点健康。
- [x] 运营手册与部署回滚记录更新，文档审计通过。

## Notes

- 用户要求替换浏览器弹窗；在完成新登录保护和验证前，旧门禁先保留，以免出现无人保护的过渡期。
- 生产机实例仍是 demo：固定短信验证码和合成数据，不能宣称真实业务生产接入。
