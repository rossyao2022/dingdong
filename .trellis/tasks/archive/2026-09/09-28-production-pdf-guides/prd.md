# 生产机试用家长与运营 PDF 操作指南

## Goal

基于 v0.3.12 生产机试用界面制作两份图文保姆级 PDF 操作指南并校验

## Requirements

- 交付家长、运营各一份可直接转发的 PDF，以当前 `https://1.15.23.152` 的 v0.3.12 生产机试用实例为准。
- 逐步写清入口、登录、主要操作、成功时会看到什么、退出与常见问题；用当前界面的截图作对照。
- 运营版包含已验证有效的后台账号与密码、图形验证码操作；家长版只给固定试用短信码，不出现后台凭据。
- 清楚说明这是生产机器上的 demo/合成数据试用实例，不能填真实儿童资料，也不把机器人与供应商演示内容写成真实上线。
- 含后台密码的 PDF 仅作为本地私密交付件，不进入 Git；正文和截图中不出现内部调试信息或失效的旧 IP/旧账号。

## Acceptance Criteria

- [x] 两份 PDF 存在，可打开，页码和中文字体正常；每页渲染检查无裁切、重叠或黑块。
- [x] 关键步骤与当前浏览器界面、代码及生产运行模式吻合。
- [x] 家长版不含后台凭据；运营版含正确账号密码；旧 `110.42.225.196` 和 `tester` 不出现。
- [x] PDF 提取文本及渲染图片复核通过，含密码的文件被 Git 忽略且权限为 0600。

## Notes

- 用户已要求把运营账号密码放入可转发版本；本任务只在私密交付件中包含它们，不写进任务记录。
