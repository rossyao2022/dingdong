# 设计

以 live Chrome 截图核对 v0.3.12 的家长和运营入口；结合代码与旧指南筛选仍有效的路径，重写两份指南。PDF 使用 ReportLab 和可嵌入中文字体，统一 A4 页面、步骤卡、截图、页脚页码。截图只取合成账号和示例家庭，不含真实资料。

源数据分离：可提交的制作脚本不写后台密码；运行时从本机已忽略的运营发放版手册读取登录信息。成品放 `output/pdf/`，该目录本机忽略；含密码 PDF 为 0600。家长 PDF 也放同目录供直接交付。

QA：Poppler 将每页渲染 PNG，逐页目视；PDF 文本提取检查版本、入口、步骤及禁词；与浏览器截图核对页面名和按钮。
