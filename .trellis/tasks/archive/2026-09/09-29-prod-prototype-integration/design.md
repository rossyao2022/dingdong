# 技术设计

## 边界

目前生产机试用实例为 v0.3.14、`APP_ENV=demo`、合成展示数据；DingDong 配置为空。对方现有 Prototype 仅 HTTP，固定 `ca_dingdong` 可用；正式服务要求 HTTPS 和我方 ULID 账号。试用实例含演示数据，不能当作正式生产数据环境。

## 实施方式

1. 先在生产机容器内以一次性进程注入测试 API 配置，调用对方健康、固定账号只读端点与正式账号绑定；不修改服务容器，不把密钥放在命令行或输出。
2. 在数据库事务内建立临时 CA 测试账户和已授权合成儿童，触发 `ca_display` 真源读取，然后回滚。只读检查不写入真实家长记录；供应商 bind 只使用测试 token 与测试账号。
3. 若固定账号可读但正式账号不可绑定、四子接口不可用，保留线上合成展示并明确阻塞点；若条件满足，备份后通过受限 env 文件配置试用实例，切换数据源并公网验收。
4. 不更改同机其他业务、不额外发送短信。任何与预期不符的结果停止切换，按证据收尾。

## 回退

一次性进程结束即撤销测试配置。若切换服务，则保留 v0.3.14 镜像和原 env 文件，重新使用原配置启动即可回退；数据库变更前备份，不执行 `down -v`。
