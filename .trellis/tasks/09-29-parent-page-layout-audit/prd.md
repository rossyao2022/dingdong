# 家长端全页面布局巡检与修复

## Goal

逐页检查家长端手机、平板、桌面真实浏览器布局，修复可复现的问题并提交推送。

## Requirements

- 覆盖未登录页、建档页、家长端全部顶层页面及可进入的详情页、关键弹窗；检查 320、390、430、768、1024、1280px。
- 核验文字、按钮和输入框可读可点，无横向溢出、明显遮挡、相邻组件紧贴或错误折行；页面无脚本错误或图片加载失败。
- 对发现的缺陷先留可复现证据，再修复；保留现有视觉、业务行为和短信/机器人配置。
- 运行必要的前端、浏览器和部署配置回归，提交并推送最新代码。除非用户另行要求，本任务不部署生产机。

## Acceptance Criteria

- [x] 巡检记录列出所有已检查的页面、视口、发现的问题与修复结果。
- [x] 新增或扩展浏览器断言，覆盖可复现的缺陷；相关回归通过。
- [x] 源码与记录提交并推送远端分支，工作区仅保留任务外原有改动。

## Notes

“其他页面”按当前上下文指家长端；运营后台为独立界面，本轮只检查未登录入口，并在巡检记录标明覆盖边界。
