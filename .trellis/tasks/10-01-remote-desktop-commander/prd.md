# 生产机 Remote Desktop Commander 接入

用户已同意建任务并实施。目标：1.15.23.152安全接入官方Remote Desktop Commander，自动安装依赖、启动、重启自动运行，完成实际文件读写、终端和进程测试并交付连接操作。

## 验收

- 实测OS/架构/Node/Python/Docker、端口、防火墙及服务。
- 官方npm发布和官方文档为来源，不用第三方安装脚本。
- 独立最小权限工作区；无主机root、sudo、Docker socket、生产密钥/DB挂载；不改SSH/核心防火墙和现有业务。
- 文件读取/创建/修改、终端命令、进程查询真实通过；完整远程连接必须区分本地工具测试与配对后ChatGPT端到端。
- 安装目录、启动停止、开机状态、连接地址、用户授权步骤清楚记录。
- 删除/SSH/核心防火墙/影响业务前说明风险。测试文件保留。
