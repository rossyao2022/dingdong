## 4. 我方已自行确定（同步给贵方，无需回复）

文档表 0 明确「CA：提供稳定 `ca_account_id`」，该事项属**我方决定**。我方已定案，同步如下（**唯一需要贵方确认的是格式可接受性，已列为 D19**）：

| 事项 | 我方决定 |
| --- | --- |
| 层级 | **账户级**——不设「家庭级」聚合层 |
| 与机器人的关系 | **一台机器人一个号**（机器人 : `ca_account_id` = 1 : 1），且**一台机器人服务一个孩子**（账户 : 孩子 = 1 : 1） |
| 换机语义 | **换一台机器人 = 换一个号**（发新号，旧号置 `retired` 归档、永不重用），不沿用原号。详见下方 D20 |
| 取值 | `ca_` + 26 位 ULID，例如 `ca_01JC8Z9K3M7QXR2V6TB4NDH5PF` |
| 生成时机 | 首次绑定前由我方生成，随绑定请求携带 |
| 生命周期 | 一经生成**永不修改、永不回收重用**；解绑后置 `retired` 归档 |
| 跨设备稳定性 | **稳定**——不绑手机号、不绑登录会话、不绑设备指纹 |
| 不透明性 | 我方不要求贵方解析其内部结构；贵方请按**不透明字符串**存储与回传 |

详细规格（含落库表结构与映射关系）见 [`设计/CA对接_C1_ca_account_id设计_20260916.md`](../设计/CA对接_C1_ca_account_id设计_20260916.md)。
