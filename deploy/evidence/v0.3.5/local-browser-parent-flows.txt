# 本地真实浏览器：家长端既有流程回归（frontend/tests/flows.spec.js）

日期：2026-09-14
环境：本地 Docker 演示环境 0.3.5 + 临时 Django 开发服务（8017，deploy 设置）
命令：cd frontend && npx playwright test tests/flows.spec.js --reporter=list

结论：5 通过 / 3 失败。三项失败与本轮改动无关，原因是这套用例本来依赖
"同一数据库上的 Django 开发服务 + Celery Worker/Beat"：
  - 两项在用例内调用 `manage.py inject_fixture`，命令用的数据库与本次临时代理服务
    不是同一个（Child does not exist），因此注入失败；
  - 一项用 Django 技术后台登录临时技术人员，临时服务上 admin 登录未通过。
与本轮直接相关的两项通过：
  - 「真实登录、活动完成、刷新恢复、退出清理」
  - 「移动端各页面、无效关联提示、资料编辑与帮助回执」（含编辑儿童档案对话框）
其余通过项：移动端布局与儿童切换、首页小岛与菜单、探索四题刷新恢复。
未通过的三项在本轮记为"未实测/环境受限"，历史结论保留，不作为本轮通过证据。
