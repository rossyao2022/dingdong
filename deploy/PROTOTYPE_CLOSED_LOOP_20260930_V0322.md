| 问题 | 处理 |

| 推送只收原始内容、没有页面数据 | 验签接收后校验共享Mock业务结构，生成不可变报告快照；幂等/非法/未知/迟到保护，拉取与最新同频率推送比较，失联回退有效同频率推送。解绑与撤权在读取后再次检查。 |
| 原绑定阻止换手机号 | 当前家长可主动解绑。旧号/家庭/儿童关联、CA答卷/报告永久保留；下一家长得到新的本地ULID，出站仍映射供应商共享ca_dingdong。数据库约束最多一个活跃演示绑定，不能抢占。 |
| 提示“刷新”误导家长 | 占用时直接提示“机器人已被其他孩子绑定，请原绑定家长先解绑，再重新绑定。”此类占用/归档不显示刷新修复；真正资料修订冲突仍可载入最新记录。 |
| 不知道是否收到推送 | 技术权限后台新增“推送接收”，查看接收/处理和各频率快照，无密钥/签名/原始家庭内容；应用INFO日志和HTTP/HTTPS精确回调access日志配置已准备。 |
