- 八维24题、8维说明及1–5档选项、分维累计、并列展示；四类指纹指南的全部观察/学习/沟通/三步活动文字：数据结构一致。
- 原型全部27份素材逐项 SHA256 相同。包含21份新增和此前已吸收的6份，不能混用“新增素材数量”和“原型素材总量”。
- 真实儿童级保存、固定题库版本、完成结果不可变、重做另建记录、历史回看、授权/过期边界有效。
- 原有 CA 登录/退出、短信冷却、儿童档案、NFC与旧22题报告流程保留。原型浏览器假档案、即时清空和静态机器人占位没有覆盖 CA 真实业务。

## 确认的遗漏与缺陷

| 优先级 | 当前问题 | 用户影响 / 补齐方向 |
| --- | --- | --- |
| P1 | **已有 CA 机器人账号的儿童执行删除资料会报500**，即使账号仍待接通也可复现 | 删除事务回滚，事项未完成。删除服务未处理受保护的 CA 关联。必须先阻止非预期500，明确普通儿童去标识与旧号永久保留方案；不能直接删号、级联删儿童或随意置空外键。固定演示号继续保护。 |
| P1 | “我的 DingDong”缺原四情境问卷直达、结果偏好分布和选引导入口 | 原四题内容仍在“测评与报告”，题目没有丢；缺的是原位置和后续操作。 |
| P1 | 原认知/模仿/逆思/开放四种网页引导没有完整保留；活动虽能选方式，但实际步骤话术不随 mode/style 变化 | 当前仍用 CA 认知/情感/创意/探索枚举并显示固定 guide_text；实测认知/情感的活动第一步话术相同，偏好刷新又回默认。需补原网页引导层及可观察效果，不能硬改现有活动/机器人枚举。 |
| P2 | 探索/成长记录没有原 JSON 导出 | 需从当前儿童真实答案、结果、版本、活动记录生成；不含令牌、验证码、NFC、指纹图片或其他儿童资料。 |
| P2 | 活动缺上一步；成长旅程缺全部/完成/跳过筛选 | 后端已有相关能力，前端操作尚未吸收。 |

| P2 | 独立新建兴趣/八维题库发布后没有家长入口；预览仅显示整库 | 当前展会应复制默认题库为新版本；需后台明确操作方式及18选9/八维计分说明。若要多题库并存，另补选择入口。 |

**上述问题目前均未修复。** 内容对应不等于动作对应，存在按钮也不等于它改变了引导结果。
