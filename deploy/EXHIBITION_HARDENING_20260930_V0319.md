# 会展稳定性修复与发布准备 v0.3.19

日期：2026-09-30。状态：**本地修复和验收完成，尚未推送或部署**。目标仍是工作人员用同一 Prototype 演示号完成 10.4 展示，不是游客真实账号或正式专业测评上线。

## 已修复

1. **固定号保护**：开启 demo 模式时，`ca_dingdong` 禁止停用和不同标签换机，服务层返回 409 `PROTOTYPE_ACCOUNT_PROTECTED`；界面隐藏两个危险入口。普通账号换机、归档规则不变。
2. **绑定恢复**：未接通时保留本页内存凭据，提供“重新连接”；重复建号 POST 复用原号并再次 bind。刷新后凭据已丢弃，页面提示再碰原标签，不再声称无需操作。
3. **绑定与数据状态**：未接通的固定号返回 409 `DINGDONG_BIND_PENDING`，不向对方查询旧聚合数值；接通后仍须家庭归属和用途授权。
4. **NFC 刷新提示**：地址栏立即清理凭据，只在 sessionStorage 记非敏感待连接标记；成功和主动取消后清除。token、电话和验证码不写入浏览器存储。
5. **短信冷却**：遵守成功响应 `retry_after` 与 429 `Retry-After`，显示剩余秒数；刷新和退出不取消发码冷却。定时器只存在于登录页。
6. **报告输入准备**：新增 `prepare_prototype_demo_report`，默认仅预检，显式 `--apply` 才补原固定号儿童的合成初始输入。核对原标签摘要、家庭、儿童、账号状态及当前发布的合成题库和模板；不同输入或故障输入拒绝覆盖。不会发布题库、插入成品报告、补造专业分数。
7. **图文指南**：手机真实 Prototype 卡片在“账户与关联”；“伙伴引导”在同页页首，手机底部没有“我的 DingDong”。家长 PDF 19 页、运营 PDF 12 页，补连接、待接通、授权、报告提交与详情、人工选方向/选伙伴/设置/聊天/回读截图。运营凭据仅保存在用户授权的本机忽略 PDF 中，不入 Git。
